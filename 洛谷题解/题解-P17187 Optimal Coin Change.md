## 题意分析

多组数据到 EOF。每种硬币无限个，凑出金额 $v$，要求：

1. **第一目标**：硬币总数最少（经典完全背包）；
2. **第二目标**：方案不唯一时，输出**使用更多低面值硬币**的方案——计数向量 $(c_1, c_2, \dots, c_n)$ 按 $c_1$ 优先的字典序最大者（样例 `40 4 1 10 13 37` 输出 `3 0 0 1` 而非 `0 4 0 0` 可验证这一点）；
3. 无解输出 `-1`。

数据范围 $v \le 2000,\ n \le 10$，非常宽松，难点不在复杂度，而在**如何把"方案"本身作为答案输出**。

## 第一层：第一反应——完全背包求最少枚数

拿到题先写最熟的东西：设 $f[j]$ 为凑出 $j$ 所需的最少硬币数，完全背包转移：

$$f[j] = \min(f[j],\ f[j - a_i] + 1)$$
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int S,n;
    while(cin >> S >> n) {
        vector<int> a(n+1);
        for(int i=1;i<=n;i++) {
            cin>>a[i];
        }

        const int INF = 0x3f3f3f3f;
        vector<int> f(S+1,INF);
        f[0]=0;
        for(int i=1;i<=n;i++) {
            for(int j=a[i]; j<=S; j++) {
                f[j]=min(f[j],f[j-a[i]]+1);
            }
        }
        if(f[S]==INF)cout << -1 << '\n';
        else {
            cout<<f[S]<<'\n';
        }
    }
}
```
这就是第一个代码。它 $O(vn)$ 就能求出最少枚数，但**输出不了方案**——题目要的答案 $c_1 \dots c_n$ 这个模板给不了。所以它只是定海神针：确认了第一目标就是个裸完全背包，剩下的问题全在"方案怎么记"。

## 第二层：错误尝试——只记"最后一枚硬币"来回溯

第二个代码的思路很自然：开 $g[j]$ 记录"把 $f[j]$ 更新到当前最优时用的那枚硬币的面值"，倒着从 $S$ 往回走就能还原方案。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int S,n;
    while(cin >> S >> n) {
        vector<int> a(n+1);
        for(int i=1;i<=n;i++) {
            cin>>a[i];
        }

        const int INF = 0x3f3f3f3f;
        vector<int> f(S+1,INF);
        vector<int> g(S+1,-1);
        f[0]=0;
        for(int i=1;i<=n;i++) {
            for(int j=a[i]; j<=S; j++) {
                if(f[j-a[i]]+1<=f[j]) {
                    f[j]=f[j-a[i]]+1;
                    g[j]=a[i];
                }
            }
        }
        if(f[S]==INF)cout << -1 << '\n';
        else {
            vector<int> cnt(n+1,0);

            int j = S;
            while(j>0){
                for(int i=1;i<=n;i++){
                    if(a[i]==g[j]) {cnt[i]++;break;}
                }
                j-=g[j];
            }
            for(int i=1;i<=n;i++) cout<<cnt[i]<<' ';
            cout<<'\n';
        }
    }
}
```

这份代码在洛谷上能 AC，但**不是正解**。反例：

```
32 4 1 2 5 7
```

$f[32] = 6$，枚数为 6 的最优方案有三个：$(0,2,0,4)$、$(1,0,2,3)$、$(0,0,5,1)$。按题意要字典序最大的 $(1,0,2,3)$，这份代码输出的是 `0 2 0 4`。我本地跑了一遍验证，确实如此。

错在哪：

- $g[j]$ 只存了一枚面值，回溯出来的链**在枚数上确实是最优的**（每步 $j \leftarrow j - g[j]$，链长恰为 $f[S]$，这可以证明），但它对"还原出哪个最优方案"完全失控——结果由转移的先后顺序（`<` 还是 `<=`、硬币的输入顺序）决定，本质碰运气；
- 根本原因是**信息量不够**。这题的目标是两级的：先枚数最少，再字典序最大。一个 `int` 只编码得了第一级目标，第二级目标塞不进去，回溯时自然无法保证。

教训：当方案本身是答案、且带有次级目标时，状态里必须携带完整的方案信息（或能推出它的结构），不能指望 O(1) 的辅助数组事后猜出来。

## 第三层：正解——把方案计数直接塞进 DP 状态

设 $\text{cnt}[j]$ 为一个长度为 $n$ 的向量：**凑出 $j$ 的最优方案**（枚数最少的前提下字典序最大）中每种硬币各用了几个。转移时和 $f$ 同步维护：

- 若 $f[j-a_i]$ 不可达，跳过；
- 若 $f[j-a_i]+1 < f[j]$：最优枚数被刷新，$\text{cnt}[j] \leftarrow \text{cnt}[j-a_i]$，第 $i$ 种 $+1$；
- 若相等（并列）：构造候选 $\text{cv} = \text{cnt}[j-a_i] + e_i$，**仅当 cv 字典序大于 $\text{cnt}[j]$ 时才替换**——不能无脑覆盖。

正确性的关键是一个归纳不变量：处理完前 $i$ 种硬币后，$\text{cnt}[j]$ 恰好是"只用前 $i$ 种、枚数最少、枚数相同则字典序最大"的方案。两类转移分别处理"更优"与"并列"，并列分支用 `vector` 自带的字典序比较显式取最大，不变量就保持住了。注意不能图省事写成 `<=` 直接覆盖——并列时覆盖成哪个方案是不确定的，字典序要求就丢了。

复杂度：每组数据 $O(v \cdot n \cdot n)$（并列时复制向量是 $O(n)$），$2000 \times 10 \times 10 = 2\times 10^5$，随便过；空间 $2001 \times 11$ 个 int，忽略不计。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int S, n;
    while (cin >> S >> n) {                    // 多测到 EOF
        vector<int> a(n + 1);
        for (int i = 1; i <= n; i++) cin >> a[i];

        const int INF = 0x3f3f3f3f;
        vector<int> f(S + 1, INF);             // 最少枚数
        vector<vector<int>> cnt(S + 1, vector<int>(n + 1, 0)); // 最优方案的计数
        f[0] = 0;

        for (int i = 1; i <= n; i++) {         // 完全背包：i 升序，j 升序
            for (int j = a[i]; j <= S; j++) {
                if (f[j - a[i]] == INF) continue;   // 不可达，避免无意义拷贝
                int cond = f[j - a[i]] + 1;
                if (cond < f[j]) {             // 枚数更优：直接继承
                    f[j] = cond;
                    cnt[j] = cnt[j - a[i]];
                    cnt[j][i]++;
                } else if (cond == f[j]) {     // 并列：取字典序更大的
                    vector<int> cv = cnt[j - a[i]];
                    cv[i]++;
                    if (cv > cnt[j])           // vector 支持字典序比较
                        cnt[j] = move(cv);
                }
            }
        }

        if (f[S] == INF) cout << -1 << '\n';
        else {
            for (int i = 1; i <= n; i++) cout << cnt[S][i] << ' ';
            cout << '\n';
        }
    }
}
```

## 总结

这题是个很好的"背包输出方案"教学样本，路径是：

1. **裸模板**确认第一目标是完全背包；
2. 想偷懒只记转移来源（$g[j]$ 回溯），发现次级目标（字典序）无法编码进 O(1) 信息，碰运气 AC 但随时会假；
3. 正解把**方案向量作为状态的一部分**同步 DP，并列时用字典序比较取最大。

核心思想一句话：**方案本身是答案时，最优子结构的"最优"必须包含你输出时要比较的那个维度**，否则DP求出的最优和你要输出的最优就不是同一个东西。
