[[次论-全源最短路]]
## 一、它叫什么名字，是个什么算法

这个算法叫 **Floyd 算法**，中文常译作**弗洛伊德算法**，由 Robert Floyd 于 1962 年发表（Warshall 同年独立给出了几乎一样的形式，所以也叫 Floyd-Warshall 算法）。

在竞赛里它有一个更形象的外号——**插点法**。这个外号不是白起的，它直接道出了算法的本质：**通过不断往路径里"插入"中转点来改进答案**。先把这句话记住，后面全部内容都是它的展开。

它是经典的**动态规划**算法，也是三大最短路算法（Dijkstra、Bellman-Ford、Floyd）里唯一的**多源最短路径**算法。

## 二、它在最短路家族里的地位

| 算法 | 单源/多源 | 能否处理负权边 | 时间复杂度 | 代码量 |
|---|---|---|---|---|
| Dijkstra（堆优化） | 单源 | ❌ 不能 | $O(m \log n)$ | 较长 |
| Bellman-Ford / SPFA | 单源 | ✅ 能 | $O(nm)$（SPFA 均态好） | 中 |
| **Floyd** | **多源（任意两点）** | ✅ 能（不能负环） | $O(n^3)$ | **极短（三重循环）** |

结论很清楚：

- 题目只求**一个起点**到各点：用 Dijkstra 或 SPFA；
- 题目要求**任意两点之间**的最短路（"每对顶点"、"相互距离"这类字眼）：**Floyd 是第一选择**；
- 点数 $n$ 一般不超过几百（$n \le 400$ 左右 Floyd 才稳过），但代码只有 5 行核心，极不容易写错。

## 三、它能干什么（用途）

Floyd 远不止"求最短路"一件事：

1. **多源最短路**：输出完整的 $d[i][j]$ 矩阵，任意两点距离一次全搞定；
2. **传递闭包**：把 `+` 换成 `|`、`min` 换成 `||`，就能求"任意两点是否连通"——这是 Warshall 当年的原始用途；
3. **判断负环**：跑完后若存在 $d[i][i] < 0$，图中就有负环；
4. **无向图最小环**：枚举 $i<j$，用 $d[i][j]$（不含边 $(i,j)$ 时的中间点路径）加上边权 $w(i,j)$ 更新答案；
5. **求图的"中心"**、改造为计数（方案数）、处理"经过边数有限制"的变形——很多图论 DP 题的骨架都是它。

## 四、核心原理：它到底在干什么

### 4.1 从一个问题出发

看这张图（5 个顶点，边权如图，无向）：



问你：$1$ 号点到 $5$ 号点的最短距离是多少？

直觉上你会枚举路线：$1\to 5$ 直达？没有边。$1 \to 4 \to 5 = 10 + 4 = 14$。$1 \to 2 \to 3 \to 5 = 3 + 2 + 6 = 11$。还有没有更短的？

 route 一多，你就需要一个系统性的方法，而不是碰运气。**Floyd 的思路是：一条最短路，无非是一串中转点的组合；我干脆按"允许哪些点当中转点"分批考虑，逐批放宽。**

### 4.2 状态定义（这是全算法的灵魂，务必背下来）

设顶点编号为 $1 \sim n$。定义：

$$d^{(k)}[i][j] = \text{从 } i \text{ 到 } j 的所有路径中，\textbf{只允许经过编号 } \le k \textbf{ 的顶点作为中转点}\text{时的最短长度}$$

读三遍这个定义，抓住两个要点：

- 端点 $i, j$ **不受限制**（可以任意大编号），限制的只是**中间路过谁**；
- $k$ 是"中转点资格上限"：$k$ 越小，允许借道的地方越少，答案只会**暂时**偏大；$k$ 一路涨上去，答案一路变好，$k=n$ 时就是真正的最短路。

初始状态（$k=0$，谁都不许当中转）是什么？就是图的邻接矩阵：

$$d^{(0)}[i][j] = \begin{cases} 0, & i=j \\ w(i,j), & (i,j) \text{ 有边} \\ +\infty, & \text{其他} \end{cases}$$

### 4.3 状态转移方程

现在想：从"只允许前 $k-1$ 个点中转"升级到"允许前 $k$ 个点中转"，多了**一个**新资格——点 $k$。那么 $i \to j$ 的最短路，按"**用不用点 $k$ 当**中转"分成两类：

**第一类：根本不用点 $k$。** 那这条路径和 $k-1$ 阶段没有任何区别，答案就是 $d^{(k-1)}[i][j]$。

**第二类：用了点 $k$。** 一条用了 $k$ 的最短路，可以拆成两段：

$$i \;\longrightarrow\; k \;\longrightarrow\; j$$

注意关键一步：既然这是**最短**路径，前半段 $i \to k$ 和后半段 $k \to j$ 各自也必须是最短的；而且前半段内部不会再绕回 $k$（否则成环，负环另说，正环去掉更短），所以这两段都只需要"前 $k-1$ 个点中转"的资格——它们的长度正是 $d^{(k-1)}[i][k]$ 和 $d^{(k-1)}[k][j]$。

这就是最优子结构。**两类取最小**：

$$\boxed{\; d^{(k)}[i][j] = \min\big( \underbrace{d^{(k-1)}[i][j]}_{\text{不用 } k},\; \underbrace{d^{(k-1)}[i][k] + d^{(k-1)}[k][j]}_{\text{用 } k \text{ 中转}} \big)\; }$$

这就是大名鼎鼎的**松弛（relaxation）**操作，画出来就是这个三角形：



用一句大白话记住它：**"经 $k$ 绕一下，比现在的记录短吗？短就更新。"**

### 4.4 为什么可以把第一维 $k$ 滚掉

定义里 $d$ 有三维，空间 $O(n^3)$，这显然不行。观察转移式右端，三项用的全是 $k-1$ 阶段的老值；而左端写的是 $k$ 阶段的新值——看似必须两份数组。但有一个精妙的事实：

$$d^{(k)}[i][k] = d^{(k-1)}[i][k], \qquad d^{(k)}[k][j] = d^{(k-1)}[k][j]$$

为什么？想 $d^{(k)}[i][k]$：从 $i$ 到 $k$ 的最短路，**终点就是 $k$，中转点资格是"前 $k$ 个点"——但路径里根本不能再出现 $k$**（$k$ 已经是终点，再来一次就成环了）。所以"允许用 $k$ 中转"这个资格对它毫无用处，它从 $k-1$ 阶段起就不变了。

结论：$k$ 阶段更新任何 $d[i][j]$ 时，凡是用到的那一行 $d[i][k]$、那一列 $d[k][j]$，都是"死值"，**本阶段内改不动**。于是直接在原数组上滚，覆盖更新完全安全：

$$d[i][j] \leftarrow \min\big( d[i][j],\; d[i][k] + d[k][j] \big)$$

这个"滚掉一维还保证正确"的论证，竞赛面试和笔试都常考，要会自己推。

### 4.5 无后效性顺带说一句

DP 要求无后效性：第 $k$ 阶段的决策不依赖未来。这里天然满足——"点 $k$ 以后还能不能用"是后面阶段的事，当前阶段只消费前 $k-1$ 阶段的成果，绝不回头。这正是 Floyd 的 DP 身份成立的原因。

## 五、代码与执行过程逐格演示

### 5.1 标准代码（背到肌肉记忆）

```cpp
const int INF = 0x3f3f3f3f;
int d[505][505], n, m;

void floyd() {
    for (int k = 1; k <= n; k++)          // ① 中转点资格 k：必须最外层！
        for (int i = 1; i <= n; i++)      // ② 起点
            for (int j = 1; j <= n; j++)  // ③ 终点
                if (d[i][k] + d[k][j] < d[i][j])
                    d[i][j] = d[i][k] + d[k][j];
}
```

初始化：

```cpp
memset(d, 0x3f, sizeof d);        // 全部置 INF
for (int i = 1; i <= n; i++) d[i][i] = 0;
for (每条边 u-v 权 w) d[u][v] = d[v][u] = min(d[u][v], w);  // 无向；有向只赋单向
```

跑完后 $d[i][j]$ 就是 $i \to j$ 的最短距离。负环检查：`if (d[i][i] < 0) 有负环`。

### 5.2 矩阵快照：算法在图上跑了一遍是什么样子

对开头那张图，把矩阵从 $k=0$ 滚到 $k=5$（蓝 = 当前正在处理的第 $k$ 行/列，橙 = 本步被更新的格子）：



我们一格一格核对，你会看到转移方程"活"了：

- **$k=1$（允许点 1 中转）**：检查所有 $i \to 1 \to j$。唯一变长的是 $2 \to 1 \to 4 = 3 + 10 = 13$，于是 $d[2][4]: \infty \to 13$（对称的 $d[4][2]$ 同理）。
- **$k=2$（再允许点 2）**：盯着第 2 行第 2 列读：$d[1][2] + d[2][3] = 3 + 2 = 5 < 8$，$d[1][3]: 8 \to 5$。其他都不优。这时 $d[1][3]$ 已经"偷偷变短"了，但 $1 \to 5$ 仍然是 $\infty$——别急，面包会有的。
- **$k=3$（再允许点 3）**：本步大丰收。用第 3 行第 3 列拼：
  - $d[1][3] + d[3][4] = 5 + 2 = 7 < 10 \Rightarrow d[1][4] = 7$
  - $d[1][3] + d[3][5] = 5 + 6 = 11 < \infty \Rightarrow d[1][5] = 11$
  - $d[2][3] + d[3][4] = 2 + 2 = 4 < 13 \Rightarrow d[2][4] = 4$（把上一步的 13 又改进了！）
  - $d[2][3] + d[3][5] = 2 + 6 = 8 \Rightarrow d[2][5] = 8$
  - 对称的下半矩阵同步更新。
- **$k=4, k=5$**：逐对检验后没有任何改进。矩阵定型。

注意两个教学要点：

1. $d[2][4]$ 的值从 $\infty \to 13 \to 4$ **被改写了两次**——这正是"分阶段放宽中转资格"的含义，也证明滚动数组覆盖更新是安全的（改 $d[2][4]$ 用的是 $d[2][3]$、$d[3][4]$，它们在 $k=3$ 阶段是死值）。
2. $1 \to 5$ 的最优路径 $1 \to 2 \to 3 \to 5$ 是**分三个阶段拼出来的**：$k=2$ 时拼好 $1 \to 3$，$k=3$ 时再把 $3 \to 5$ 接上。Floyd 不追求一次到位，它"积小胜为大胜"。

## 六、为什么 $k$ 必须在最外层（高频错误）

初学者最爱把三重循环写成 `for i for j for k`——这相当于对每个 $(i,j)$ 枚举一次中转点，但此时 $d[i][k]$ 可能还是"没用过任何中转"的原始值，把还没长大的半成品当成成品用，结果必然错。

一句话：**外层循环的变量，是"DP 的阶段"；阶段必须从小到大推进，前一阶段全部完成后才允许开启下一阶段。** $k$ 是阶段，所以 $k$ 必须在最外层。$i, j$ 在同一阶段内谁前谁后无所谓。

反例记忆法：$1 \to 2 \to 3 \to 4$，若 $k$ 在内层，算 $d[1][4]$ 时 $d[2][4]$（需要 $k=3$ 先处理）还没被更新，链条断在中间。

## 七、复杂度与适用边界

- 时间：$\Theta(n^3)$，三层各 $n$ 次，无优化空间；
- 空间：$O(n^2)$，一个矩阵；
- 适用范围：$n \lesssim 400$（$400^3 = 6.4 \times 10^7$，C++ 一秒内）；边数 $m$ 无关——**这是它和 Dijkstra 的本质区别，边稠密时 Floyd 反而划算**；
- 负权边：可以放心用；负环：跑出 $d[i][i] < 0$ 即判断成功，但矩阵其余值不再可信。

## 八、易错点清单（考场自查用）

1. 初始化对角线 $d[i][i] = 0$，漏了会全错；
2. 重边取 $\min$，自环视情况（负自环 = 负环）；
3. `INF` 取 `0x3f3f3f3f`（约 $1.06 \times 10^9$），两个 INF 相加不爆 int（$2 \times 0.3\text{f} \approx 2.1\times10^9 < 2^{31}-1$）——这是 `0x3f3f3f3f` 比 `0x7fffffff` 高明的地方；保险起见比较前可写 `if (d[i][k] < INF && d[k][j] < INF)` 或干脆开 `long long`；
4. $k$ 必须在最外层（见第六节）；
5. 有向图只赋单向，无向图赋双向。

## 九、一句话总复习

> Floyd = 以"中转点资格上限 $k$"为阶段的 DP，状态 $d[i][j]$ 存"只用前 $k$ 个点中转时的最短路"，每阶段对所有点对做一次松弛 $d[i][j] = \min(d[i][j],\, d[i][k]+d[k][j])$。$O(n^3)$ 换"一次跑出全源全汇"，代码五行， negative权不惧，但怕负环、怕 $n$ 大。
