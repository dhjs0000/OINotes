## 一、这是什么？——先认识它

**LCA**，全称 **Lowest Common Ancestor**，中文叫**最近公共祖先**。

什么叫"公共祖先"？想象一棵家族树：每个人有一个父亲，往上可以追溯到爷爷、曾爷爷……如果两个人往上追溯，他们的祖先中一定有重合的部分——这些重合的祖先就是"公共祖先"。

什么叫"最近"的公共祖先？就是在所有公共祖先中，**深度最深**（离这两个人最近）的那一个。

举个具体的例子，看图（一棵树）：

```
            1
          /   \
         2     3
        / \   / \
       4   5 6   7
      / \
     8   9
```

- 节点 8 的祖先链：8 → 4 → 2 → 1
- 节点 9 的祖先链：9 → 4 → 2 → 1

它们公共的祖先是 4、2、1，其中**最近（最深）** 的是 **4**。

再举几个，你试试心算：

- `lca(8, 5)`：8 的链是 8→4→2→1，5 的链是 5→2→1，公共的是 2 和 1，最近的是 **2**。
- `lca(8, 6)`：8→4→2→1，6→3→1，公共的只有 1，答案是 **1**。
- `lca(5, 6)`：同理，答案是 **1**。
- `lca(4, 9)`：注意，4 本身就在 9 的祖先链上！这种情况公共祖先包括 4、2、1，最近的是 **4**。也就是说，**一个点是另一个点的祖先时，LCA 就是这个祖先本身**。这个性质很重要，后面写代码会用到。

**它的地位与重要性**：LCA 是树论中最基础、最常用的算法之一。[[次论-倍增思想]]求 LCA 的思想（**二进制拆分 + 预处理**）更是整个 OI 界公认的"倍增全家桶"的核心成员——倍增做法全家桶包括：LCA、ST 表求 RMQ、树上差分、Kruskal 重构树等。可以说，**学懂了倍增 LCA，就等于拿到了通往一系列进阶算法的入场券**。

## 二、它有什么用？——应用场景

LCA 不是纯理论玩具，它出现的频率极高：

1. **求两点间距离**：树是特殊的图（无环），两点间路径唯一。两点间距离可以神奇地用深度和 LCA 表示出来：

$$dist(u,v) = dep[u] + dep[v] - 2 \cdot dep[\text{lca}(u,v)]$$

这个公式怎么用，我们后面会专门证明。

2. **树上路径问题**：树上任意两点路径上的权值和、最大值、最小值等，都可以用 LCA 拆成两段处理（`u → lca` 和 `lca → v`）。

3. **树上差分**：统计"路径上每个点被经过多少次"这类问题，经典做法就是对 `(u, v)` 这条路径做差分，差分的操作必须用到 LCA：

```
cnt[u]++, cnt[v]++, cnt[lca]--, cnt[fa[lca]]--
```

4. **各类模板题**：比如洛谷 P3379（模板：最近公共祖先）、P1967（货车运输，Kruskal 重构树）、各种树上莫队、树上启发式合并的题目中，LCA 往往是作为工具出现的。

一句话总结：**凡是涉及"树上两点之间怎么走"的问题，几乎都会碰到 LCA**。

## 三、思路：从暴力到倍增

### 3.1 最暴力的做法：向上跳

既然 LCA 是两个点的"最近的公共祖先"，那最直观的想法就是：

> 先让两个点**爬到同一深度**，然后两个点**一起一步一步往上爬**，直到爬到同一个节点。

怎么爬？沿着父亲指针往上爬即可。

代码骨架：

```cpp
int lca_slow(int u, int v) {
    // 第一步：拉到同一深度
    while (dep[u] > dep[v]) u = up[0][u];   // up[0][x] 是 x 的父亲
    while (dep[v] > dep[u]) v = up[0][v];
    // 第二步：一起往上爬
    while (u != v) {
        u = up[0][u];
        v = up[0][v];
    }
    return u;
}
```

这个做法完全正确！但是太慢了：最坏情况下（比如树退化成一条链，两个点分别在链的两端），需要跳 $O(n)$ 次。$n \le 5 \times 10^5$ 时，每次询问跳几十万步，$m$ 次询问就是几亿次操作，直接超时。

**问题出在哪？出在"一步一步跳"上。** 如果一次能跳很多步，不就好了吗？

### 3.2 关键思想：预处理"一次跳 $2^k$ 步"

这里就出现倍增的灵魂了。我们先想清楚一个问题：

> 如果我们能预先知道每个点"往上跳 $2^k$ 步到达的节点"，那么一次跳跃可以跨 $2^k$ 级。

为什么偏偏是 $2^k$（1, 2, 4, 8, 16, …）而不是 3、5、7 这样的数？

因为**任何正整数都能唯一地拆成若干个 2 的幂次之和**——这就是二进制表示！比如：

$$13 = 1101_2 = 8 + 4 + 1$$

也就是说，往上跳 13 步 = 先跳 8 步 + 再跳 4 步 + 再跳 1 步。**3 步操作就取代了 13 次一步一步爬**。一般来说，跳 $x$ 步需要拆出 $O(\log x)$ 个 2 的幂，每步查询都是 $O(1)$。

这就是倍增 LCA 的总复杂度：**预处理 $O(n \log n)$，每次查询 $O(\log n)$**，轻松通过 $5 \times 10^5$ 的规模。

### 3.3 倍增表的定义与递推

我们定义：

> $up[k][u]$ = 从节点 $u$ 出发，往上走 $2^k$ 步后到达的节点。

- $k=0$：$up[0][u]$ 就是 $u$ 的父亲（往上走 1 步）。
- $k=1$：$up[1][u]$ 就是往上走 2 步，即 $u$ 的祖父。
- 一般地，$up[k][u]$ 是 $u$ 的 $2^k$ 级祖先。

**这个表怎么填？递推！** 这是倍增最漂亮的性质：

> 往上跳 $2^k$ 步 = 先跳 $2^{k-1}$ 步，再跳 $2^{k-1}$ 步。

也就是说：

$$\boxed{up[k][u] = up[k-1]\big[\,up[k-1][u]\,\big]}$$

翻译成大白话：$u$ 先跳 $2^{k-1}$ 步到 $up[k-1][u]$，再从那个点再跳 $2^{k-1}$ 步。两段拼起来正好 $2^k$ 步。每格只需要查一次表，$O(1)$ 转移。

对照你的代码：

```cpp
up[0][u] = fa;                                  // k=0：直接是父亲
for (int k = 1; k < LOG; k++)
    up[k][u] = up[k-1][ up[k-1][u] ];           // 递推式
```

**为什么 LOG 取 20？** 因为 $2^{19} = 524288 > 5 \times 10^5$，20 层足够覆盖 $n \le 5 \times 10^5$ 的任何跳跃。一般来说取 $\log_2 n$ 上取整即可，比赛里常写 20 或 17。

**一个容易忽略的细节**：DFS 时我们会传 `fa`（父亲），但**根节点的父亲是它自己**（`dfs(s, s)`），这样 `up[k][s] = s`，向上跳会安全地停在根，而不是越界。这是好习惯，务必记住。

## 四、深度怎么求？——DFS 与 BFS 都行

LCA 算法的前提是知道每个点的深度 `dep[]`。求深度有两种标准写法：

### 4.1 DFS 版

```cpp
void dfs(int u, int fa) {
    up[0][u] = fa;
    dep[u] = dep[fa] + 1;
    for (int k = 1; k < LOG; k++)
        up[k][u] = up[k-1][ up[k-1][u] ];
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
    }
}
```

DFS 天然是沿着树一条枝走到底，深度就是"递归层数"。**注意这里在 DFS 入口就顺便填好了该节点的整个倍增表**，每访问一个节点 $O(\log n)$，总共 $O(n \log n)$。

**隐患提醒**：这题（洛谷 P3379）树的大小 $5 \times 10^5$，DFS 递归深度可能达到 $5 \times 10^5$ 层，有爆栈风险。评测机栈空间足够时没问题，但保险做法是：

```cpp
// 扩大栈空间（Windows），或者干脆改成 BFS
```

### 4.2 BFS 版

```cpp
void bfs(int root) {
    queue<int> q;
    depth[root] = 0;
    q.push(root);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int i = head[u]; i; i = nxt[i]) {
            int v = to[i];
            if (v == fa[u]) continue;
            depth[v] = depth[u] + 1;
            fa[v] = u;
            q.push(v);
        }
    }
}
```

BFS 是一层一层扩展的，天然保证"先访问父亲、后访问儿子"，所以计算儿子深度时父亲深度一定已知。BFS **用队列代替递归栈，彻底免除爆栈之忧**，$n$ 很大时（尤其链状树）强烈推荐。代价是要手写邻接表（或用 `vector` 也行）。

两种写法等价，选一个喜欢的记住即可。

## 五、核心：倍增 LCA 查询详解

现在来看整个算法的重头戏。查询分**三个阶段**，我们逐个拆解。

### 5.1 第一步：让两个点深度对齐

```cpp
if (dep[u] < dep[v]) swap(u, v);   // 保证 u 更深
int d = dep[u] - dep[v];
for (int k = LOG - 1; k >= 0; k--)
    if (d >> k & 1)
        u = up[k][u];
```

思想：**让更深的那个点独自向上跳 `d` 步，跳到和另一个点同一深度**。

为什么 `swap`？只是为了下面代码统一让 `u` 更深，少写一半分支。

关键技巧：`d >> k & 1` 检查 `d` 的第 `k$` 位二进制是否为 1。为 1 就说明 `d` 的拆分中包含 $2^k$，于是让 `u` 跳 $2^k$ 步。从高到低枚举 $k$，每位最多跳一次，正确性由二进制拆分的唯一性保证。

例子：`d = 13 = 1101_2`，循环中会跳 $2^3$（8 步）、$2^2$（4 步）、$2^0$（1 步），共 13 步。✔

### 5.2 第二步：特判"一个点是另一个点的祖先"

```cpp
if (u == v) return u;
```

回忆前面讲的性质：如果 $v$ 在 $u$ 的祖先链上，那么深度对齐后 `u == v` 成立，此时 **LCA 就是 v 本身**，直接返回。

这一步绝对不能省！很多初学者（包括我自己当年）第一次写会忘掉它，导致答案错误。记住这个反例：树是一条链 $1-2-3-4$，查询 `lca(2, 4)`，深度对齐后 `u` 跳到 2，`u == v`，必须在这里返回 2。如果没有这步，后面的循环会一路跳到根，返回错误的 1。

### 5.3 第三步：两个点一起向上跳

```cpp
for (int k = LOG - 1; k >= 0; k--) {
    if (up[k][u] != up[k][v]) {
        u = up[k][u];
        v = up[k][v];
    }
}
return up[0][u];
```

这一步是整个算法最精妙的地方，它的核心规则是：

> **跳到"公共祖先的下面"，而不是跳到公共祖先。**

为什么？因为一旦 $up[k][u] == up[k][v]$，说明 $2^k$ 步之外那个点**已经是公共祖先了**——但 LCA 要的是"最近"的那个，跳过头了就错了。所以我们只在"跳过去之后还不会汇合"的情况下才跳。循环结束时，`u` 和 `v` 恰好停在 **LCA 的两个儿子** 上，于是再跳一步 `up[0][u]` 就是答案。

从高到低枚举 $k$ 的意义：高位决定大步，如果大步跳过去不汇合就赚大了；如果会汇合就放弃，留给更小的步数去试探。**这个"从大到小试跳"的技巧是倍增类算法的通用套路**（ST 表查询同理），一定要内化。

**为什么一定要从高到低？** 从高到低枚举，等价于"贪心二进制拆分"：先确定最高位，每一位一旦确定就不再反悔，结果唯一。如果从低到高枚举，低位先跳可能跳到错误位置（跳过头无法回退）。这就是为什么 ST 表和倍增跳跃都要 `for (k = LOG-1; k >= 0; k--)`。

## 六、完整代码回顾（含注释版）

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 500005;
const int LOG = 20;                    // 2^19 > 5e5，足够

int n, m, s;
vector<int> g[MAXN];
int dep[MAXN];
int up[LOG][MAXN];                     // up[k][u]: u 的 2^k 级祖先

// DFS：求深度 + 填倍增表，up[k][u] = up[k-1][ up[k-1][u] ]
void dfs(int u, int fa) {
    up[0][u] = fa;
    dep[u] = dep[fa] + 1;
    for (int k = 1; k < LOG; k++)
        up[k][u] = up[k-1][ up[k-1][u] ];
    for (int v : g[u])
        if (v != fa) dfs(v, u);
}

// 倍增 LCA
int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);   // u 更深
    int d = dep[u] - dep[v];
    for (int k = LOG - 1; k >= 0; k--)
        if (d >> k & 1) u = up[k][u];  // 二进制拆 d，拉齐深度
    if (u == v) return u;              // v 是 u 的祖先
    for (int k = LOG - 1; k >= 0; k--)
        if (up[k][u] != up[k][v]) {    // 跳过去还不汇合才跳
            u = up[k][u];
            v = up[k][v];
        }
    return up[0][u];                   // 此时 u、v 是 LCA 的两个儿子
}

int main() {
    cin >> n >> m >> s;
    for (int i = 1; i < n; i++) {
        int u, v; cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    dfs(s, s);                         // 根的父亲是自己，防越界
    while (m--) {
        int u, v; cin >> u >> v;
        cout << lca(u, v) << '\n';
    }
    return 0;
}
```

复杂度：预处理 $O(n \log n)$，每次查询 $O(\log n)$，空间 $O(n \log n)$（约 $20 \times 5\times10^5 \times 4\text{B} \approx 40\text{MB}$，注意开静态数组或卡准空间限制）。

## 七、扩展：两点距离公式及其证明

最后讲这个必考公式的来历。

$$\boxed{dist(u, v) = dep[u] + dep[v] - 2 \cdot dep[lca(u, v)]}$$

**为什么？** 画一条路径来看：从 $u$ 到 $v$ 的唯一路径形如"先从 $u$ 爬到 $c = lca(u,v)$，再从 $c$ 下降到 $v$"。

- $u$ 到 $c$ 的距离 = $dep[u] - dep[c]$（深度之差）
- $c$ 到 $v$ 的距离 = $dep[v] - dep[c]$

相加：

$$dist(u,v) = (dep[u] - dep[c]) + (dep[v] - dep[c]) = dep[u] + dep[v] - 2\,dep[c]$$

就这么简单。代码：

```cpp
int dist(int u, int v) {
    return dep[u] + dep[v] - 2 * dep[lca(u, v)];
}
```

**例题**：洛谷 P1967（货车运输）、P4427（异或 distance）、各类"树上路径计数"题都是套这个公式。

## 八、易错点清单（考前必看）

1. **忘写 `if (u == v) return u;`**——祖先关系查询直接 WA。
2. **第三步的循环里写的是 `up[k][u] != up[k][v]` 而不是 `u != v`**——混淆两者是初学者第一杀手。
3. **二进制循环必须从高到低**（`k = LOG-1 → 0`）。
4. **根节点父亲设为自己**（`dfs(s, s)`），否则 `up[k]` 递推越界。
5. **链状树 DFS 爆栈**——$n$ 大时考虑 BFS 或扩栈。
6. **LOG 开不够**——$n$ 到 $10^6$ 时记得开到 21（$2^{20} \approx 1.05\times10^6$）。
7. `d >> k & 1` 的运算符优先级：`>>` 和 `&` 中 `>>` 优先级更高，但写 `(d >> k) & 1` 更保险。

## 九、小结

倍增 LCA 的三板斧：

| 步骤 | 内容 | 复杂度 |
|---|---|---|
| 预处理 | DFS/BFS 求深度，递推 `up[k][u] = up[k-1][up[k-1][u]]` | $O(n\log n)$ |
| 查询① | 深的点按二进制拆位跳到同一深度 | $O(\log n)$ |
| 查询② | 从高到低试跳，只在不汇合时跳，最后 `up[0][u]` | $O(\log n)$ |

记住一个核心心法：**"能跳就跳，跳过头就停；二进制拆分，从大到小贪心。"** 这句话不仅适用于 LCA，也适用于 ST 表、倍增求 k 级祖先等所有倍增类算法。掌握了它，你在树论算法这条路上就站稳了。
