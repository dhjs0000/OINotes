## 1. 名称与定位

分组背包（Grouped Knapsack），是 01 背包的四大经典变形之一（其余三个是完全背包、多重背包、二维费用背包）。

在竞赛里的地位可以用一句话概括：**凡是"若干选一"的决策问题，几乎都是分组背包**。它本身的模板题不难，但作为思想工具出场频率极高——NOIP2006 提高组《金明的预算方案》、各类"主件+附件"购物题、资源调度题，背后都是分组背包。掌握它的关键不在背代码，而在理解它相对 01 背包到底"变"在了哪里。

## 2. 问题定义

给你 $N$ 组物品，第 $i$ 组有 $s_i$ 个物品。每个物品有体积 $v$ 和价值 $w$。**每组物品中你至多选一个**（也可以整组都不选）。给定容量为 $M$ 的背包，求能装下的最大价值总和。

和 01 背包对比着看：

| | 01 背包 | 分组背包 |
|---|---|---|
| 决策对象 | 单个物品 | 一整组物品 |
| 每个物品的决策 | 选 / 不选 | 选它所属那一组的某一个 / 不选 |
| 约束 | 每件最多一次 | **每组最多一个** |

也就是说：01 背包问的是"这件物品要不要"，分组背包问的是"这一组里挑哪一个，还是干脆不挑"。

## 3. 应用场景

什么时候该想到分组背包？看两个特征：

1. 物品天然被划分成若干**互斥**的类别（颜色、型号、主件与它的附件……）；
2. 同一类里只能取一个，不同类之间才谈得上"都装进去"。

典型例子：

- **金明的预算方案**：主件和它的若干个附件构成一组，买了附件必须买主件——每组里有"只买主件""主件+附件1""主件+附件2"……若干种方案，每组选一种；
- **选课/选装备**：几个时间段冲突的课程、同槽位的装备，每组挑一个；
- **二维费用的特例**：把"种类"当成一种额外费用，每组费用为 1。

## 4. 核心思想：把"选哪个"塞进转移方程

用 01 背包的框架去想。01 背包的转移是：

$$f[i][j] = \max\big(f[i-1][j],\ f[i-1][j-v_i] + w_i\big)$$

两个候选：不选第 $i$ 件，或选第 $i$ 件。

分组背包只是把一个决策换成了多个决策：第 $i$ 组有 $s_i$ 个候选。所以转移方程自然长成：

$$f[i][j] = \max\Big(f[i-1][j],\ \max_{1\le k\le s_i}\big\{f[i-1][j-v[i][k]] + w[i][k]\big\}\Big)$$

其中：

- $f[i][j]$：考虑完前 $i$ 组、背包剩余容量为 $j$ 时的最大价值；
- $v[i][k]$、$w[i][k]$：第 $i$ 组第 $k$ 个物品的体积和价值；
- $f[i-1][j]$ 这一项代表"第 $i$ 组什么都不选"，它由初始化或上一轮转移自然继承下来，不用单独写。

三层循环的含义：

```
i 循环：依次处理每一组（外层，保证"每组"这个约束生效）
j 循环：枚举当前剩余容量
k 循环：枚举这一组里选哪一个物品
```

## 5. 空间优化：滚动数组，以及为什么体积要倒序

观察转移方程，$f[i][\cdots]$ 只用到 $f[i-1][\cdots]$，第一维可以滚掉：

$$f[j] = \max\big(f[j],\ f[j - v[i][k]] + w[i][k]\big)$$

滚掉之后有个必须想清楚的问题：式子里的 $f[j]$ 和 $f[j-v]$，到底代表 $f[i-1][\cdot]$ 还是 $f[i][\cdot]$？

**这取决于体积 $j$ 的枚举方向。**

- **倒序枚举**（从 $M$ 到 0）：处理到 $j$ 时，$j - v[i][k] < j$ 还没被本轮（第 $i$ 组）更新过，$f[j-v]$ 仍是上一组的值 → 正确，相当于 $f[i-1][j-v]+w$。
- **正序枚举**：$j-v$ 在本轮已经被第 $i$ 组更新过了，$f[j-v]$ 里可能已经装了第 $i$ 组的某个物品 → 同一个组的两个物品会被同时选进去，**直接破坏"每组至多一个"的约束**。

举个具体例子感受下。容量 $M=10$，第 $i$ 组里有两个物品：$(v=3,\ w=5)$、$(v=4,\ w=7)$，前面各组的最优值存在 $f$ 里。假设正序枚举，处理到 $j=6$ 时：

$$f[6] = \max(f[6],\ f[3] + 5)$$

而 $f[3]$ 在这一轮刚刚被更新成"选 $(3,5)$ 这个物品"的值——于是 $f[6]$ 就变成了同一个物品选两次。同组物品互相"传染"，约束就失效了。倒序枚举时 $f[3]$ 还保持上一组的值，就没这个问题。

所以正确写法是 **j 倒序、且 j 循环必须在 k 循环外面**：

```cpp
for (int i = 1; i <= n; i++)          // 组
    for (int j = m; j >= 0; j--)      // 容量，倒序！
        for (int k = 0; k < (int)g[i].size(); k++)   // 组内物品
            if (j >= g[i][k].v)
                f[j] = max(f[j], f[j - g[i][k].v] + g[i][k].w);
```

顺序不能交换。如果把 k 放外层、j 放内层（即使 j 倒序），就变成对组内每个物品各做一次 01 背包——同组物品成了独立物品，照样会多选。实在想交换也可以，但要用临时数组把"上一轮"的值存下来：

```cpp
for (int i = 1; i <= n; i++) {
    auto old = f;                     // old 就是 f[i-1]
    for (auto &it : g[i])
        for (int j = m; j >= it.v; j--)
            f[j] = max(f[j], old[j - it.v] + it.w);
}
```

## 6. 完整代码

读入方式一（洛谷 P1757 格式：每个物品带组号）：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXM = 1000 + 5;
const int MAXT = 40 + 5;

long long f[MAXM];
vector<int> v[MAXT], w[MAXT];   // v[i][k] 体积，w[i][k] 价值

int main() {
    int m, n, t;                // m 容量，n 物品总数，t 组数
    cin >> m >> n >> t;

    for (int i = 1; i <= n; i++) {
        int vi, wi, ti;
        cin >> vi >> wi >> ti;  // 体积 价值 所属组
        v[ti].push_back(vi);
        w[ti].push_back(wi);
    }

    for (int i = 1; i <= t; i++)
        for (int j = m; j >= 0; j--)
            for (int k = 0; k < (int)v[i].size(); k++)
                if (j >= v[i][k])
                    f[j] = max(f[j], f[j - v[i][k]] + w[i][k]);

    cout << f[m] << '\n';
    return 0;
}
```

读入方式二（先给组数，每组开头给个数，再逐个给物品）：

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Item { int v, w; };

int main() {
    int n, m;
    cin >> n >> m;                      // n 组，m 容量
    vector<vector<Item>> g(n + 1);
    for (int i = 1; i <= n; i++) {
        int s; cin >> s;
        g[i].resize(s);
        for (auto &x : g[i]) cin >> x.v >> x.w;
    }

    vector<long long> f(m + 1, 0);
    for (int i = 1; i <= n; i++)
        for (int j = m; j >= 0; j--)
            for (auto &it : g[i])
                if (j >= it.v)
                    f[j] = max(f[j], f[j - it.v] + it.w);

    cout << f[m] << '\n';
}
```

## 7. 复杂度

设物品总数 $S = \sum_{i=1}^{N} s_i$：

- 时间复杂度 $O(M \times S)$：每个容量、每个物品配对一次；
- 空间复杂度 $O(M + S)$：滚动数组后只剩一维 DP 加存储物品。

$M \le 10^3$、$S \le 10^4$ 的规模随便过；如果 $M$ 很大（$10^5$ 以上）且物品多，要考虑 meet-in-middle 或按价值贪心等变形，那是另一个话题了。

## 8. 易错点清单

1. **j 正序** → 同组物品多选。这是最高频的错误，样例弱的时候能"碰巧过"，交上去就挂。
2. **k 循环放到 j 外面** → 同组物品变成互相独立的 01 物品。检查方法：造一组数据，组里放两个体积都为 1、价值都为 1 的物品，$M=1$，答案必须是 1，输出 2 就说明写错了。
3. **数组开不够**：组数、容量按题目数据范围开，宁大勿小。
4. **初始化**：$f$ 全 0 对应"可以不选任何组"，答案是 $f[M]$；若题目要求**恰好装满**背包，$f[0]=0$、其余 $-\infty$，答案同样取 $f[M]$。
5. **价值爆 int**：价值和超过 $2^{31}$ 时记得开 `long long`。
