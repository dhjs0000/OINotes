[[根论-动态规划]]
## 01背包
每个物品最多选一次。核心一句：倒序枚举容量，保证每件物品只用一次。
```
for 物品 i:
    for j = V downto w[i]:
        f[j] = max(f[j], f[j-w[i]] + v[i])
```
## 记忆点：倒序 = 只取一次；正序 = 退化成完全背包。

## 完全背包
每个物品无限件。核心一句：和01只差一个容量枚举方向。
```
for 物品 i:
    for j = w[i] to V:      // 正序
        f[j] = max(f[j], f[j-w[i]] + v[i])
```
## 记忆点：正序允许"重复使用"，因为 `f[j-w]` 可能已含物品 i。

## 分组背包
物品分若干组，每组最多选一个。核心一句：加一层组内枚举，组内对容量倒序。
```
for 组 k:
    for j = V downto 0:
        for 组内物品 i:
            if j >= w[i]:
                f[j] = max(f[j], f[j-w[i]] + v[i])
```
## 记忆点：先枚容量再枚组内物品，防止同一组被取两次。等价于01背包里"每组是一坨捆绑决策"。

## 带条件的背包（泛化约束）
容量之外多一个约束维度（如重量+体积、件数限制、方案计数）。
核心一句：状态加一维，转移多一个循环（或判断）。
```
f[j][k] = max(f[j][k], f[j-w[i]][k-c[i]] + v[i])
```
常见变体速记：
- 二维费用背包：`f[v][m]`，两维都倒序（等价01）
- 求方案数：`max` 换 `sum`，初始化 `f[0]=1`
- 求具体方案/字典序：倒推，`f[j]==f[j-w]+v` 说明选了 i
- 恰好装满 vs 至多：恰好装满初始化 `f[0]=0`、其余 `-INF`；至多全 `0`

## 一图流总记忆：01倒、完全正、分组多一层；二维加一维，计数改求和，装满负无穷。
